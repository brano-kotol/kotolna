# Kotolňa · Timel

Prehľadný panel pre kotol so zásobníkom štiepky a reguláciou **Timel SKZP-02**.

- Živá schéma kotolne: zásobník, podávač, ventilátor, zapaľovacia špirála, plameň, 4-cestný zmiešavač, ÚK1 a TÚV
- Grafy dňa, štatistika horáka, prehľad 7 dní
- Úprava nastavení regulátora (cez e.timel.pl)

Aplikácia beží priamo v prehliadači: https://brano-kotol.github.io/kotolna/
Prihlásenie je rovnaké ako na e.timel.pl. Heslo ani prihlasovací token sa neukladajú nikam inam než do vášho prehliadača.
